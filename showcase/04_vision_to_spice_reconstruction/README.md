# 04 — Vision-to-SPICE Schematic Photo Reconstruction

> **Demonstrates reconstructing a complete, wired LTspice `.asc` schematic and `.cir` netlist from an incomplete photo or hand-drawn sketch of a circuit diagram.**

---

## 1. Overview & The Missing-Parameter Problem

When users photograph a circuit diagram from a textbook, whiteboard, or lab notebook, components frequently lack values, transistors lack part numbers, or supply rails lack numeric voltages. Standard LLMs hallucinate arbitrary values silently, causing simulation failure.

AI-SPICE solves this via a two-stage protocol:
1. **Interactive Audit (`mode="ask_user"`)**: Identifies every missing value, computes analytical E24 recommendations, and presents an interactive table to the user (`missing_params_audit_prompt.md`).
2. **Autonomous Synthesis (`mode="autonomous"`)**: Sizes missing bias resistors, transistors, and bypass capacitors from first principles to meet target specs ($V_E = 1.15\text{ V}$, $A_v = 10\text{ V/V}$), then compiles a 16-pixel grid signal-wired schematic.

- **`demo3_reconstructed_from_photo.cir`**: Reconstructed SPICE netlist with calculated E24 component values and `.meas` directives.
