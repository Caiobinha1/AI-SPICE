## 2. Circuit Operation & AI Sizing Decisions

1. **Topology**: Second-order series RLC network driven by a $50\,\Omega$ source generator and terminated into a $1\text{ k}\Omega$ load.
2. **AI Analytical Sizing**:
   - Given target $f_0 = 1\text{ MHz}$ and $Q \approx 6.7$, theoretical values were computed:
     $$L = \frac{Q \cdot R_{total}}{2\pi f_0}, \quad C = \frac{1}{(2\pi f_0)^2 L}$$
   - Snapped to standard E24 values via `ai_spice.sizing.snap_to_series`:
     - $R_1 = 100\,\Omega$ (E24)
     - $L_1 = 150\,\mu\text{H}$ with realistic ESR $R_{ser} = 2.4\,\Omega$
     - $C_1 = 160\text{ pF}$ (E24)
3. **Schematic Layout**:
   Compiled to `demo1_rlc_bandpass.asc` on the 16-pixel grid with full orthogonal signal wiring and zero floating pins (`NC_ = 0`).
